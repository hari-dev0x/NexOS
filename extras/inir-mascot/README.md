# Kira Mascot Art Pack

This directory contains the official Kira mascot art pack for iNiR (`inir-mascot` release v3).

## Contents

- `inir-mascot-pack.tar.gz` — Upstream compressed asset bundle (33.4 MB).
- `extracted/` — 354 verified pose PNGs and looping GIF animations.
- Verified Asset Tree SHA-256: `85f8c2671aafc161d21bd59176bfc9b4eed02c6d983b655bcfac61c354df4398`
- Archive SHA-256: `0c29161ce55affb37d165183f9775506ec974679567fedcabf72e9f5ff5ac39b`

## Status & Behavior

- The Kira companion character is **disabled by default** in settings.
- All 354 art assets are verified and installed in `config/quickshell/reimagined/assets/images/mascot/`.
- If you wish to enable the mascot companion, open iNiR Settings → Mascot and toggle the companion switch on.
